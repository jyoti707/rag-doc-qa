Python Programming Basics

Source: Open technical documentation and standard references (public knowledge, paraphrased)

This document gives a short overview of Python Programming Basics.

The def keyword is used to define a function in Python. A list is mutable, which means it can be changed after creation, whereas a tuple is immutable. A dictionary stores data as key-value pairs and is written with curly braces.

Python uses indentation to mark blocks of code instead of curly braces. The function range(5) produces the numbers 0, 1, 2, 3 and 4. The len function returns the number of items in a list, string or other collection.

An f-string, written with the prefix f, lets expressions be placed inside curly braces within a string. A comment in Python starts with the hash symbol.
