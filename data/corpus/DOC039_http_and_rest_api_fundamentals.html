HTTP and REST API Fundamentals

Source: Open technical documentation and standard references (public knowledge, paraphrased)

This document gives a short overview of HTTP and REST API Fundamentals.

HTTP status code 200 means OK and 201 means a resource was created. HTTP status code 404 means the requested resource was not found. HTTP status code 500 indicates an internal server error.

Status 401 means authentication is required, while 403 means access is forbidden even if authenticated. The four common HTTP methods are GET to read, POST to create, PUT to update and DELETE to remove a resource. REST APIs are stateless, meaning each request must carry all information needed to process it.

HTTP uses port 80 by default and HTTPS uses port 443. JSON is the most common data format for exchanging data in REST APIs.
