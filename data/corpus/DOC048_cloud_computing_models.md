# Cloud Computing Models

*Source: Open technical documentation and standard references (public knowledge, paraphrased)*

This document gives a short overview of Cloud Computing Models.

## Key points

The three main service models are IaaS, PaaS and SaaS. IaaS provides virtual machines, storage and networks, and Amazon EC2 is an example. PaaS provides a platform for developers to run applications without managing servers, and Google App Engine is an example.

SaaS delivers complete software over the internet, and Gmail is an example. Cloud deployment can be public, private or hybrid. Elasticity means resources can grow or shrink automatically with demand.

Pay-as-you-go pricing charges customers only for the resources they use. Serverless services such as AWS Lambda run code in response to events without the user managing servers.
